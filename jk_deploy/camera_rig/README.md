# Four-Camera Tripod Rig Versions

- [`v1/`](v1/README.md) is the frozen first revision: friction pivots, flat
  TechNexion shelves, and the captured tripod nut.
- [`v2/`](v2/README.md) is the current revision: 15-degree pivot indexing,
  screwless TechNexion cradles, an ISO 1222 stabilizing-pin hole, and modeled
  mounting hardware.

Start with v2 for new prints. Both versions retain their own generator,
print-ready STL files, editable STEP files, assembly model, and preview.
